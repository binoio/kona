# Kona 2.1.1

Kona 2.1.1 stabilizes the menu bar remaining time display, eliminating width jitter and icon shifting as seconds count down.

## Fixed

- **Stable menu bar remaining time** — the remaining time display now uses a fixed-width, monospaced-digit countdown sized precisely for `00:00:00` next to the cup icon. The menu bar icon and adjacent items no longer shift or jitter as digits change from second to second.

## Notes

- Requires macOS 14 (Sonoma) or later
